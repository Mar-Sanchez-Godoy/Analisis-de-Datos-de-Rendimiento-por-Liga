# Métricas GA – Lionel Messi y Cristiano Ronaldo
Análisis Comparativo de sus Carreras (Goles + Asistencias)

### GA (Goals + Assists) representa la suma de los goles y las asistencias registradas por cada jugador. En este proyecto se utiliza como métrica principal para analizar y comparar la contribución ofensiva de Lionel Messi y Cristiano Ronaldo a lo largo de sus carreras a nivel de clubes.
